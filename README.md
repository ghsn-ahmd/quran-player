# 🌙 مشغّل القرآن الكريم

مشغّل صوتي للقرآن الكريم والأذكار، صفحة ويب واحدة بدون سيرفر ولا حسابات. تختار مجلد التلاوات من جهازك ويعمل منه مباشرة، والملفات لا تُرفع لأي مكان.

> صدقة جارية — الكود مفتوح المصدر، انسخه وعدّله وانشره كما تشاء، وأسأل الله أن يتقبّل.

## المميزات
- تعرّف تلقائي على السور من اسم السورة (عربي أو إنجليزي) أو رقمها في عنوان الملف أو اسمه أو اسم المجلد.
- تبويبان: القرآن والأذكار، وتصنيف الأذكار حسب الكلمات (أذكار، دعاء، تسبيح، استغفار…) أو اسم المجلد.
- بحث يتجاهل التشكيل وفروق الهمزات.
- مشغّل كامل ومصغّر، عشوائي وتكرار، سحب شريط التقدم، والتحكم من شاشة القفل.
- وضع فاتح وداكن وتلقائي، وعرض شبكة أو قائمة.
- يحفظ المكتبة في المتصفح لتجدها في الزيارة التالية.
- يعمل بدون إنترنت بعد التثبيت.

## طريقة الاستخدام
1. افتح الصفحة واضغط **اختر مجلد الصوتيات**.
2. اختر المجلد الذي فيه الملفات (mp3, m4a, wav, ogg, aac, flac, opus, webm).
3. اضغط أي سورة لتشغيلها.

### تسمية الملفات
الأفضل أن يحتوي **عنوان الملف (ID3)** على اسم السورة (`سورة البقرة`) أو رقمها. يكفي أحد هذه:
- اسم السورة بالعربي في العنوان أو اسم الملف: `سورة الكهف`.
- اسم لاتيني: `Al-Baqarah` أو `Surah Yasin`.
- رقم السورة: `002.mp3`.
- مجلد باسم السورة بداخله الملف.

للأذكار: ضع في الاسم أو العنوان أو اسم المجلد كلمة مثل **أذكار** أو **دعاء** أو **تسبيح** أو **استغفار**.

## التثبيت كتطبيق ويب (PWA)
يلزم فتح الصفحة عبر **https** (مثل GitHub Pages).
- **أندرويد (Chrome):** القائمة ⋮ ← *تثبيت التطبيق* أو *إضافة إلى الشاشة الرئيسية*.
- **آيفون (Safari):** زر المشاركة ← *إضافة إلى الشاشة الرئيسية*.
- **الكمبيوتر (Chrome/Edge):** أيقونة التثبيت في شريط العنوان.

## المتصفحات
- **Chrome / Edge:** اختيار المجلد المباشر مع كل المميزات.
- **Safari / Firefox:** يعمل بطريقة اختيار المجلد البديلة.

## النشر على GitHub Pages
1. ارفع كل ملفات المستودع إلى فرع `main`.
2. من **Settings ← Pages** اختر *Deploy from a branch* ثم `main` و `/ (root)`.
3. بعد دقيقة يظهر الرابط `https://USERNAME.github.io/REPO/`.

## هيكل المشروع
```
index.html            التطبيق كاملًا
manifest.webmanifest  إعدادات التثبيت
sw.js                 العمل بدون إنترنت
icons/                الأيقونات
```
عند تعديل أي ملف بعد النشر، غيّر رقم `V` في `sw.js` ليصل التحديث للمستخدمين.
